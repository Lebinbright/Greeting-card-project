# DIY LED Greeting Card Project

## 1\. Project Description

This project demonstrates how to create a creative
greeting card using paper craft and a simple
electronic circuit with an LED.

## 2\. Objective

To combine art, creativity, and basic electronics
to design an interactive greeting card.

## 3\. Components Required

* CR2032 Coin Cell Battery (3V)
* LED
* A4 Paper
* Origami Paper
* Glue
* Scissors
* Tape

## 4\. Working Principle

The CR2032 coin cell battery provides electrical
energy to the LED.

When the LED is connected with the correct polarity,
it emits light and creates a glowing effect
inside the greeting card.

## 5\. Construction Process

1. Take an A4 sheet and fold it into a greeting card.
2. Use origami paper to create decorative designs.
3. Place the LED in the desired position.
4. Connect the LED to the CR2032 coin cell battery.
5. Secure the circuit safely inside the card.
6. Decorate the card with creative paper designs.

## 6\. Applications

* Birthday Greeting Cards
* Festival Greeting Cards
* Handmade Gift Cards
* Creative STEM Activities

## 7\. Learning Outcomes

* Understand the basic working of an LED.
* Identify the positive and negative terminals.
* Understand how a coin cell battery supplies energy.
* Explore the combination of electronics and art.
